# iPhone duo 五件式滑动护轴手机壳

## 用户要求
五件独立零件：1 弹性半包背盖，四角内收卡住中框，顶部音量键及侧面电源/拍照键镂空；2 柔性护轴薄片，前端胶粘前盖、后端滑入背盖，双凸点/双长槽导向；3 背盖内侧独立压盖限制薄片脱出；4 完整覆盖正面的前盖，仅设置薄片粘接凹槽；5 独立胶粘镜头保护圈，粘在背盖外侧的浅凹座内。

## 本版公开默认值与边界
- 前盖按覆盖外屏的完整实心翻盖解释，不是开窗前框；使用外屏时需掀开前盖。
- 交付为结构试配 STEP，不是开模或已验证的实机壳。默认镜头孔 55 × 23 mm、圆角11.5 mm，中心以背盖中心为原点 (10,42.5) mm。轮廓圆角暂取10 mm。
- 背盖 TPU 95A，底板3.4 mm（向外加厚1 mm，手机安装基准不动）、侧壁1.6 mm；单侧安装余量0.25 mm；四角扣边向内0.4 mm。该软壳薄壁方案不是通用硬塑料FDM结构壁厚规则的认证。
- 护轴片厚0.6 mm；主护轴覆盖高度117.8 mm；滑动尾段为避开镜头缩窄，尾段有两条平行长槽。外露直立护轴段约12 mm，另加圆弧过渡、滑动尾部和前端胶接区，不能把整张薄片的展开料长限制为11.3 mm。
- 按自由段展开料长预留16.926548 mm收纳位移，双槽前向可动18.55 mm。展开时的实际运动和回缩量必须实机试验，不能仅由11.3 mm厚度推导为已验证的运动学。
- 压盖 PETG，三边胶接固定台阶，左侧为薄片入口；不得向槽内点胶。前盖 PETG，薄片粘接区留胶厚0.2 mm；胶种与TPU表面处理需粘接小样验证。胶是工艺辅料，不增加五个定制零件数量。
- 默认底部中央大开口用于避免遮挡尚未精确定位的接口/扬声器，不宣称其接口尺寸已经核验。
- 手机本体不作为自造替代实体导入，STEP仅包含壳的五件。
