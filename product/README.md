# iPhone duo 宝可梦图鉴护轴壳

## 产品与外形
机械试配模型，基础五件为半包背盖、柔性护轴片、整面内盖板、完整实心前盖、独立摄像头保护圈；另有五个正面、八个内侧装饰嵌件，共18个装配对象。蓝白半球为一体双色件，在STEP内保留两个颜色区域。
按用户要求，从转轴开口侧缩减3.1 mm，保留另一侧外边和按键基准。前后壳外宽84.7、高121.5 mm；世界X范围[-40.8,43.9]，中心X1.55。内盖板宽81.9、高118.6；前盖台阶宽82.3、高119、深1.4。
此前闭合117.8×84.1×11.3、展开117.8×164.6×5.2 mm为用户参考尺寸，无官方机械图。缩减后的CAD贴机宽81.0 mm为派生试配目标，保留0.25/边间隙，不能据此称实际手机尺寸已测量或保证实机适配。

## 摄像头与内侧圆角
摄像头外孔和保护圈内孔按新参考图采用两端圆滑、上下边微收拢的轮廓，保留57.5×23.5 mm包络，外侧端R11.75、转轴端R10.8，两圆端由公切线连接。该平面轮廓仍是照片拟合默认。贴机面Z2.4处内侧空间按外孔等距向外扩4 mm，包络65.5×31.5；从贴机面向外至小孔基准Z-1.5，深3.9 mm。采用平缓放大的截面连续放样形成圆滑弧面，没有内外同尺寸直通壁或直角阶梯。现有背板3.4 mm，局部外口毛坯增加0.5 mm以容纳该深度，随后加工深0.4的保护圈胶接浅座；其座底Z-1.1，环底Z-1.25、环顶Z-2.6，底部胶隙0.15，环厚1.35。
壳内外侧角R12、转轴侧R1；前盖和配套盖板沿用减宽后的圆角轮廓。照片无精确半径，形状仍需实机试配。

护轴片沿轴宽80.6、厚0.6，Y中心13.7、胶端8、自由中性长16.926548、尾长26.9，总展开51.826548。双长槽23.3×4.2、中心距弯端13.9，双销Ø3.2、Y=-11.3/38.7，间距50，横向间隙0.5/边。轴向中心总行程20.1；自由段加滑尾43.826548对收纳45.9，名义端余2.073452，回缩16.926548后槽销余程1.123452。材料默认TPU95A背盖、TPU片、PETG其余壳件，胶种及实物工艺待校准。
