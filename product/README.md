# iPhone duo 宝可梦图鉴护轴壳

## 产品与外形
机械试配模型，基础五件为半包背盖、柔性护轴片、整面内盖板、完整实心前盖、独立摄像头保护圈；另有五个正面、八个内侧装饰嵌件，共18个装配对象。蓝白半球为一体双色件，在STEP内保留两个颜色区域。
按用户要求，从转轴开口侧缩减3.1 mm，保留另一侧外边和按键基准。前后壳外宽84.7、高121.5 mm；世界X范围[-40.8,43.9]，中心X1.55。内盖板宽81.9、高118.6；前盖台阶宽82.3、高119、深1.4。
此前闭合117.8×84.1×11.3、展开117.8×164.6×5.2 mm为用户参考尺寸，无官方机械图。缩减后的CAD贴机宽81.0 mm为派生试配目标，保留0.25/边间隙，不能据此称实际手机尺寸已测量或保证实机适配。

## 摄像头与内侧圆角
摄像头避空沿图2圈出的整片玻璃阴影区域，壳孔和保护圈内孔同形。依照片比例暂取57.5×23.5 mm，中心(10,43)；转轴侧端半圆R11.75，靠外侧端R6、保留直段。保护圈由内孔等距向外2 mm，壳座由内孔向外2.2 mm，胶接座深0.4、底部胶层0.15。保护圈厚1.35，凸高仍基于镜头高4 mm的假设留0.5余高。
壳内靠外侧的上下角R12、转轴侧内角R1；外侧壳圆角R13.6、转轴侧外角R1。前盖、台阶和盖板配套轮廓同步，台阶R12.35、盖板R12.15。图片未提供精确半径，以上均为可调拟合默认。

护轴片沿轴宽114、厚0.6、胶端8、自由中性长16.926548、尾长26.9，总展开51.826548。双长槽23.3×4.2、中心距弯端13.9，双销Ø3.2、Y间距50，横向间隙0.5/边。轴向中心总行程20.1；自由段加滑尾43.826548对收纳45.9，名义端余2.073452，回缩16.926548后槽销余程1.123452。材料默认TPU95A背盖、TPU片、PETG其余壳件，胶种及实物工艺待校准。
