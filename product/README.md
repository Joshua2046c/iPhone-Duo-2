# iPhone duo 宝可梦图鉴前盖护轴壳

## 用户要求
基础壳五件独立零件：弹性半包背盖、柔性护轴片、独立压盖、完整实心前盖、独立胶粘镜头圈。按20260924T090840800Z-1-mark.png及此前说明，将背盖内侧滑槽、双定位销、收纳台阶和压盖全部移到前盖内侧；护轴片另一端直接胶粘背盖。打开两条直角边并拢时，护轴片需完整收纳在前盖凹槽；用户允许改变片宽。固定胶接段仍须留在背盖，完整收纳按其余自由段和滑动尾片解释。
保留前背盖左直右圆的折叠轮廓、背盖顶底回边、右侧扣边与按键避空、完整遮外屏前盖及镜头保护圈。

## 尺寸来源和默认值
用户此前图示闭合117.8×84.1×11.3、展开117.8×164.6×5.2mm，仅作参考尺寸，无官方机械图。未据此认证真实折叠运动。摄像头55×23、中心(10,42.5)、凸高4，右侧角半径10及按键开口均沿用可调默认；左角为名义方角。镜头圈外59×27、座深0.4、胶层0.15；不能宣称已高过真实镜头。
本轮默认：
- 前背盖包络各87.8×121.5mm；背板厚3.4、贴机Z2.4、壁1.6、安装单边余量0.25、扣边内收0.4不变。
- 背盖内侧胶座长8.3×高115、深1.2；护轴片固定端8×114×0.6，胶层0.2。
- 前盖由2.2增厚至4mm；收纳腔沿滑动方向49mm、宽115.4mm、深2.6，保留名义底厚1.4；正面浅座处剩余1.2。前盖仍不设屏幕窗口。
- 护轴片统一沿铰链方向加宽至114mm、居中，相对117.8mm机身两端各留1.9mm；滑动尾长30、固定端8、直立段11.9、两弯中性半径1.6，厚0.6。
- 双槽22.5×3.2、双销Ø2.4，固定销间距50。独立压盖51×118.6×1，内面让位0.2，前盖三边胶座胶层0.2；胶不得进入滑道。
- 材料默认TPU95A背盖、柔性TPU片、PETG前盖/压盖/镜头圈。胶品及表面处理未验证；不增加螺钉。

## 打开端点验收
按两直边名义接触构造打开端点，胶端不移动；自由片中性展开料长11.9+π×1.6=16.926548mm，加30mm滑尾共46.926548mm，收纳腔49mm，尾端余量2.073452mm。双槽前向极限18.05mm，达到打开端点仍留1.123452mm余程。自由段与尾片在同一凹槽内，胶端留背盖，不以缩短薄片伪造收纳。
CAD闭合及打开端点均检查五实体无体积相交；打开前后两盖直边为名义零间隙接触。凹槽底面/薄片0.35mm、侧边0.7mm/边，槽宽/销直径0.4mm/边；实体端点检查不能代替实物公差验证。

## 验证边界与交付
交付参数化STEP，现为10个装配对象、11个材料区域实体；蓝白一体嵌件占两个共面颜色区域。护轴片沿用单独展平展示姿态。闭合与打开姿态复现数据见design/duo_case/README.md，证据见fit-notes.md。
当前没有真实手机铰链扫掠体、连续运动和摩擦模型。开盖姿态不是由手机展开宽164.6mm推导的真实手机运动轨迹。不能保证装机后自动回缩、每个中间角度无干涉、贴机/保护效果、疲劳或跌落表现。后续需真实铰链轨迹、相机及按键测量，并做薄片屈曲、摩擦、槽口撕裂及胶接试验。没有生成打印设置或制造放行。

## 本轮切边及长度校核
按本轮文字要求移除后壳铰链侧上下残留竖边及该向内扣，保留顶底横向回边和右侧扣边；此为已公开的默认解释，新标记截图未收到，见references/hinge-widening-request.md。切边可能降低实物保持力，需试拉脱。
护轴宽114（约机身117.8的96.8%），背胶槽宽115；前盖收纳宽115.4，压盖118.6、侧胶边1.4、胶座119；盖体外尺寸不变，座外边框各1.25、槽底1.4mm。
闭合两水平片中面Z1.7与16.8，间距D15.1=手机11.3+背端偏移0.7+前端偏移3.1。中性半径r1.6，直段D−2r=11.9，两90°弧总长πr=5.026548，故自由包覆长16.926548，总平料长8+16.926548+30=54.926548mm（建议名义54.93，非已校准下料尺寸）。本次加宽不需要加长。上下水平片内侧Z2.0、16.5，间距14.5；手机假定Z2.4–13.7落在其内。只证明给定包络下的U形外侧包覆，并非轴端密封或真实铰链全外形认证。

## 正面装饰
按用户参考图，右侧中部为朝内（向左）的黄色三角嵌件，下半部为两端半圆的长条浅凹槽。左上蓝色半球与白色圆底座是一个双色一体嵌件；右侧红黄绿三个小球等距，正视图顶边与蓝色半球对齐。新增五个嵌件，原五件装配关系沿用。
默认尺寸：蓝色半球R7、底座Ø18×1，中心(-29,44)；小球R1.8、中心(-10,49.2)、(-3,49.2)、(4,49.2)，节距7，轮廓顶边均Y51。三角7×9×0.9，中心(34,0)。下槽34×2.4，中心(0,-44)。单位mm，前盖中心为原点，Y正为顶部。
所有浅槽深0.2，嵌件座单边留0.15、底部留0.05胶层，嵌入0.15；收纳腔上方最薄处1.2。蓝白一体件在STEP中是两个无间隙、共面的颜色区域，联合后为一个连续实体；按一个双色件共同成形。小球采用半球头和平底薄座，均为装饰件。浅座依赖胶接固定；实际强度与公差需试样。
