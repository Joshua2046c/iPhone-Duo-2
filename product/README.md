# iPhone duo 前盖收纳式五件护轴壳

## 用户要求
五件独立零件：弹性半包背盖、柔性护轴片、独立压盖、完整实心前盖、独立胶粘镜头圈。按20260924T090840800Z-1-mark.png及本轮说明，将背盖内侧滑槽、双定位销、收纳台阶和压盖全部移到前盖内侧；护轴片另一端直接胶粘背盖。打开两条直角边并拢时，护轴片需完整收纳在前盖凹槽；用户允许改变片宽。固定胶接段仍须留在背盖，完整收纳按其余自由段和滑动尾片解释。
保留前背盖左直右圆的折叠轮廓、背盖四角内扣与按键避空、完整遮外屏前盖及镜头保护圈。

## 尺寸来源和默认值
用户此前图示闭合117.8×84.1×11.3、展开117.8×164.6×5.2mm，仅作参考尺寸，无官方机械图。未据此认证真实折叠运动。摄像头55×23、中心(10,42.5)、凸高4，右侧角半径10及按键开口均沿用可调默认；左角为名义方角。镜头圈外59×27、座深0.4、胶层0.15；不能宣称已高过真实镜头。
本轮默认：
- 前背盖包络各87.8×121.5mm；背板厚3.4、贴机Z2.4、壁1.6、安装单边余量0.25、扣边内收0.4不变。
- 背盖内侧胶座长8.3×高85、深1.2；护轴片固定端8×84×0.6，胶层0.2。
- 前盖由2.2增厚至4mm；收纳腔沿滑动方向49mm、宽85.4mm、深2.6，保留底厚1.4。前盖仍不设屏幕窗口。
- 护轴片统一沿铰链方向缩窄至84mm、居中，不再覆盖全117.8mm高度；滑动尾长30、固定端8、直立段11.9、两弯中性半径1.6，厚0.6。
- 双槽22.5×3.2、双销Ø2.4，固定销间距50。独立压盖51×90×1，内面让位0.2，前盖三边胶座胶层0.2；胶不得进入滑道。
- 材料默认TPU95A背盖、柔性TPU片、PETG前盖/压盖/镜头圈。胶品及表面处理未验证；不增加实体或螺钉。

## 打开端点验收
按两直边名义接触构造打开端点，胶端不移动；自由片中性展开料长11.9+π×1.6=16.926548mm，加30mm滑尾共46.926548mm，收纳腔49mm，尾端余量2.073452mm。双槽前向极限18.05mm，达到打开端点仍留1.123452mm余程。自由段与尾片在同一凹槽内，胶端留背盖，不以缩短薄片伪造收纳。
CAD闭合及打开端点均检查五实体无体积相交；打开前后两盖直边为名义零间隙接触。凹槽底面/薄片0.35mm、侧边0.7mm/边，槽宽/销直径0.4mm/边；实体端点检查不能代替实物公差验证。

## 验证边界与交付
交付参数化五件STEP，默认展示打开并拢收纳状态。闭合与打开姿态复现数据见design/duo_case/README.md，证据见fit-notes.md。
当前没有真实手机铰链扫掠体、连续运动和摩擦模型。开盖姿态不是由手机展开宽164.6mm推导的真实手机运动轨迹。不能保证装机后自动回缩、每个中间角度无干涉、贴机/保护效果、疲劳或跌落表现。后续需真实铰链轨迹、相机及按键测量，并做薄片屈曲、摩擦、槽口撕裂及胶接试验。没有生成打印设置或制造放行。
