# iPhone duo 图鉴整面内盖护轴壳

## Design intent
五件基础壳、五件正面装饰、八件内侧装饰，共18个装配对象、19个材料区域实体。蓝白半球为一件双色连续嵌件。护轴片单独展平摆在壳右侧；其余保持闭合展示位置。
内侧护轴片盖板改为略小于前盖的整面左直右圆轮廓，八个内侧装饰槽全部在盖板，前盖不再承载这些内侧槽。盖板与前盖有配套周边台阶。外侧装饰和背壳沿用既有设计。

## 轮廓依据
转轴侧单侧缩减3.1为用户明确要求；CAD名义贴机宽81.0=参考84.1−3.1，仅是派生试配目标，不把照片当成实机尺寸认证。参考图1给手机轮廓，图2圈出完整摄像头玻璃；默认玻璃57.5×23.5、外端R11.75/转轴端R10.8，两端圆滑微收拢，内腔外侧R12、转轴侧R1，均可调。内腔宽81.5，外宽84.7。右侧和按键世界基准保留，转轴侧结构收短。装饰独立嵌件维持尺寸，浅座继续对应。

## 摄像头内外两层空间
摄像头外孔和保护圈内孔按新参考图采用两端圆滑、上下边微收拢的轮廓，保留57.5×23.5 mm包络，外侧端R11.75、转轴端R10.8，两圆端由公切线连接。该平面轮廓仍是照片拟合默认。贴机面Z2.4处内侧空间按外孔等距向外扩4 mm，包络65.5×31.5；从贴机面向外至小孔基准Z-1.5，深3.9 mm。采用平缓放大的截面连续放样形成圆滑弧面，没有内外同尺寸直通壁或直角阶梯。现有背板3.4 mm，局部外口毛坯增加0.5 mm以容纳该深度，随后加工深0.4的保护圈胶接浅座；其座底Z-1.1，环底Z-1.25、环顶Z-2.6，底部胶隙0.15，环厚1.35。
构建几何断言通过：过渡切削体Z方向深度3.9 mm；内侧开口包络在X/Y方向都比外孔增加8 mm（每侧4 mm）。当前模型19实体有效；保护圈与背壳实际最小间隙0.15 mm。上述3.9以贴机平面为起点，0.5补厚是局部毛坯，扣除胶接浅座后后壳最外局部表面Z-1.1；不要把全后板厚度改成3.9。圈顶增加的外凸需实物校核。

## 短边滑片、缩短长槽与配套空间
明确按51.826548 mm短边缩减：开槽端裁13.820413（原长×0.8/3），胶接端裁3，得到35.006135×114×0.6。恢复114 mm长边及Y中心0；新胶端5、滑尾13.079587，自由弯曲段16.926548。两条封闭长槽同步从23.3改为9.479587×4.2，槽心距弯端6.989794、Y±25。前盖收纳长度32.079587、宽115.4，X[-40.8,-8.720413]；前盖销X-32.720413、Y±25。盖板背面让位终点X-8.920413、Y±57.9；背盖胶接座5.3×115、Y中心0。外盖、摄像头及装饰维持当前版。

功能冲突待用户选择：原要求“两片壳打开后两条直边并拢，且完整护轴自由段和滑动尾片收纳在前盖内。”未修改。缩短后的封闭槽配Ø3.2柱，最大轴向中心行程仅6.279587 mm（当前闭合位置向收纳方向可用4.229587），小于完整收纳需要的16.926548。当前交付可审阅尺寸与静态配合，不能称完整开盖收纳已验证；可选择采用短行程版、保留完整收纳并改导向结构，或暂保留两项作为未满足例外。

## Making and assembly
默认背盖TPU95A、片柔性TPU0.6mm、前盖/压盖/镜头圈PETG。没有打印机配置或G-code。片宜平片制作后弯曲；此前闭合STEP不能直接作为平片下料姿态，本轮已将该片单独展平。平料名义114×35.006135×0.6，双槽随平片姿态源定义；不能把整个料长截成16.93。若FDM可试0.15mm层高四层并实测摩擦/撕裂，不保证未校准打印机的间隙。前盖外平面朝下、腔朝上；压盖平面朝下、胶座朝上。背盖外面朝下，剩余扣边悬伸用小样确认，避免支撑污染轨道。
先把双槽套在前盖销上，整面盖板周边与右侧固定承台施胶留0.2层，铰链口及左侧滑动腔不涂胶，禁止进胶滑道；固化后手动试滑，再胶接背盖固定端留0.2层。镜头圈留0.15胶层，禁止溢入镜孔。先空壳慢开合检验片不屈曲、盖不脱胶，再用尺寸样块低力扣合；不要强扣实机。拆下先掀自由侧扣边；拆压盖先取手机。镜头圈可脱胶更换，不以镜头作撬点。整面盖板沿周边台阶定位，靠近滑道的胶边较窄，装配定位和胶量更敏感；切边后保持力下降，必须试拉脱。胶种/TPU处理未测，无疲劳跌落记录。左侧两角已设R1.0小圆角，四处按键/接口开口轮廓设R1.0、外缘设R0.3圆角；打印后仍需清除毛刺，实际握感以试样为准。

正面装饰件单独制作、平底朝下，球面朝上；蓝白嵌件按一个多色部件共同成形，白底与蓝球共面连接，不留装配间隙。球面颜色区域联合后须保持一个连续件。五个嵌件均干配检查后薄涂胶入座；0.05胶层与0.2浅槽是模型默认，实物先做工艺校准，不靠大力压入。上盖正面浅槽若朝下打印，应检查槽口首层压扁与跨桥是否封槽，不能只按未装饰的平面设置切片。局部1.2薄底不承载撬动，拆件先软化/解除胶接，不撬穿槽底。本轮未做胶接、打印或强度实测。

内侧八件平底朝下制作，蓝白凹线朝上；凹线深0.25与0.7薄片需要匹配层高并做试样。盖板新增0.2外皮与本体一体成形，非另加一片零件。先将盖板暂定位于前盖，干配八个嵌件；八件都在盖板各自浅座内薄涂胶，避免胶液沿周边缝流入前盖和滑道。固化后再试拆盖板和滑动。内侧嵌件凸出0.6，装真机前用测量样块核对屏幕及保护膜净空；本轮没有进行实物打印、粘接或屏幕接触试验。

背壳外面朝下打印时，新增0.3深凹刻应检查首层压扁、桥接及支撑残留，确认0.8线宽可辨识；没有实物打印验证。

摄像头内侧有较大的弧形避让，外侧局部补厚与保护圈一起干配后再胶接；不可把外孔直接扩大4 mm来代替内侧空间。FDM试样注意弧面过渡和薄边质量，无实物适配记录。

几何检查：spine包络35.0061×114×0.6，两个封闭槽完整；槽端圆弧R2.1、直段5.2796，对应槽总长9.4796。前盖收纳顶面X[-40.8,-8.7204]、Y±57.7，盖板让位X终点-8.9204，前盖/盖板最小间隙0.2。未把19实体无碰撞等同于完整开合验证。
