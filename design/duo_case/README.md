# iPhone duo 图鉴整面内盖护轴壳

## Design intent
五件基础壳、五件正面装饰、三件独立内侧嵌件，共13个装配对象、14个材料区域实体。蓝白半球为一件双色连续嵌件。护轴片单独展平摆在壳右侧；其余保持闭合展示位置。
内侧护轴片盖板改为略小于前盖的整面左直右圆轮廓，三处独立嵌件浅座及五处一体浮雕都在盖板，前盖不承载这些装饰。盖板与前盖有配套周边台阶。外侧装饰和背壳沿用既有设计。

前盖装饰面与后盖外背面的外周均做R0.8滚圆，外包络83.7×121.5保持。直边圆柱过渡半径实测0.8，右侧大圆角处以相切环面衔接；前盖外面圆角Z18.05–18.85，后盖外面圆角Z-1–-0.2。镜头区域、内侧扣边及胶接承台的设定尺寸保持。前盖分界浅槽保留并开至圆角外边。装配无体积相交，实物握感及制作质量仍需样件确认。

转轴两端均补齐对称小台阶，朝手机侧抬高1.4 mm，端面Z14.85与内盖板外露面齐平；包络X[-39.8,-38.6]、Y[-59.5,-57.85]及[57.85,59.5]，与盖板侧向留0.2。仅两处局部台阶保留，转轴侧其余连续窄边仍清除。

前盖标记曲边下凹面补高1.2 mm，与旁边阶梯同为世界Z16.25平面；补高范围从大R角结束切点X30.3至外侧曲边，内侧三处矩形磁铁槽及其局部包围支承取消，深收纳腔边界连续。剩余深收纳腔70.1×115.7、深2.6 mm，X[-39.8,30.3]、上下端边2.9。完整自由段和滑尾43.356135×115.3平面轮廓仍可放入；容量检查不代表固定桩导向行程足够。
