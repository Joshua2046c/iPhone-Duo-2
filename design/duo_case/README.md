# iPhone duo 左直边内置滑轨手机壳

## Design intent
五个实体：back_cover弹性半包背盖、spine柔性护轴片、retainer内埋压盖、front_cover完整实心前盖、camera_guard独立胶粘镜头保护圈。依据straight_left_image及用户明确纠正：折叠外屏正视左铰链侧直边、左上左下近直角，右侧两角圆滑。前背盖、背盖内腔与扣边同步改为此非对称轮廓。名义左角采用方角；右侧半径保留既有默认，图片不足以测定实际微圆角。未恢复已撤回的宽腔、跨槽桥及端部裁短。交付fit_check，不是官方尺寸认证。

## Interfaces
phone_fit：闭合参考117.8×84.1×11.3，后半机厚5.2；左为X负、顶部Y正。盖体包络87.8×121.5保持。左外角/内腔角/扣边角方形，右背盖内腔半径10、外半径11.6，前盖右角半径11.6。背板厚3.4，手机贴合面Z2.4、外背面Z=-1；半包壁1.6、侧隙0.25、四角内扣0.4及按键避空保留。图片仅支持轮廓方向，真实角部与夹持仍需试配。
slider：恢复版本原内侧深槽底Z0.2，尾片Z0.45–1.05，双销Ø2.4顶Z1.3，压盖内面Z1.4。压盖顶Z2.2，低于手机安装面0.2；固定胶座Z1.0、胶接面Z1.2，胶层0.2。两槽14.5×3.2，容许相对闭合[-0.8,+11.3]mm，正向端没有额外余量。薄片厚0.6、高117.8，直立段11.4；尾片18.5×73，压盖33.1×78.6不变。没有声称完整自由片已能收入背盖。
front_bond：完整实心前盖仅改平面左轮廓；原胶接凹槽和0.2mm胶层不动。
camera_guard_bond：独立胶囊圈内孔55×23、外59×27，中心(10,42.5)不变；外座59.4×27.4深0.4，环底Z=-0.75、座底Z=-0.6，胶层0.15、径向隙0.2。镜头凸高4mm是假定，圈顶Z=-2.1，比假定镜头顶向外多0.5，须实测。

## Connections
free实现：四角弹性角扣；薄片/背盖双销双槽；压盖/背盖三边胶接；薄片/前盖槽胶接；镜头圈/背盖浅座胶接。胶不增加实体，手机不以自造替代实体导入。

## Validation boundary
检查五个连通实体、闭合前盖左直右圆、隐藏前盖后的背盖内腔/四角轮廓、原内置滑轨保留、镜头独立圈及静态干涉。build54五实体、10配对无体积相交；背盖/压盖原右边名义接触0mm并非新干涉；生产公差仍需试配。护轴片、压盖、镜头圈与build52形状hash、参数和刚体位置完全相同。保留原11.3mm端点行程限制；真实折叠扫掠、自动回缩、疲劳、跌落和镜头凸高未验证。

## Making and assembly
原型默认背盖TPU95A，薄片柔性TPU0.6 mm，压盖和前盖PETG；新增镜头圈也默认PETG。没有选择打印机或输出G-code。薄片宜平片制作后弯曲，STEP显示安装后的曲面形状，不能把此姿态直接当作平片下料图。薄片若FDM制作可先试0.15 mm层厚、四层形成0.6 mm，再实测摩擦/撕裂；不保证未校准打印机的配合。
先从背盖内侧把薄片两槽套上定位销，再在压盖三条固定胶边施胶，禁止胶进入滑道；安装另一端到前盖槽，留0.2 mm胶层并定位固化。镜头圈放入背盖外侧浅座，留0.15mm胶层，防止胶流入镜头孔。所有胶固化后检查压盖不高于手机贴合面，最后装手机，先用尺寸样块低力试扣，不可强行扣实机。取下时先掀自由侧两个弹性角，拆内侧压盖前必须取出手机。镜头圈可脱胶更换，禁止以镜头作撬动支点。胶种与TPU表面处理未实测；没有疲劳或跌落测试记录。
左角目前采用名义方角，制造后边缘需无毛刺，后续可按实测做小倒钝，不能再改回与右侧一样的大圆角。
