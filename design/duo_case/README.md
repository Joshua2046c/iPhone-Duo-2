# iPhone duo 图鉴双面装饰／前盖收纳壳

## Design intent
基础壳五件：back_cover弹性背盖、spine柔性片、retainer内压盖、front_cover实心前盖、camera_guard镜头圈。滑动/收纳/双销及压盖在前盖内侧，固定片胶接背盖，左直右圆轮廓保留。此前切边按铰链侧上下残留竖边解释，保留顶底回边与右侧扣边。本轮用户20260924T095306161Z-1-mark.png要求只将护轴片打平作为独立分件，总展开长度与轮廓不变。
护轴片沿用build85的展示/分件状态：护轴片展平并独立摆于壳体右侧，没有复制第六件；原有四件保留闭合位置；上盖外表面新增装饰浅槽，背盖增加握持圆角，镜头圈形状不变，盖板装饰面增加齐平薄层与定位槽。不是当前仍胶接或联动的装配姿态。

## Interfaces
保留所有装配尺寸。各盖87.8×121.5，背板3.4、贴机Z2.4、壁1.6、内扣0.4；铰链侧X[−43.9,−41.7]且Z≥2.4的原竖边移除。背胶座8.3×115深1.2，胶层0.2。前盖厚4，49×115.4深2.6收纳腔、51.4×119深1.4压盖座；压盖51×118.6×1，侧胶边1.4、端胶边2.3。双销Ø2.4，X−18.9,Y±25。
护轴片114宽、0.6厚，胶端8、滑尾30；自由中性料长11.9+π×1.6=16.926548，总平料长54.926548mm。双槽22.5×3.2，沿片Y±25间距50，平片槽心局部X−33.926548。没有缩放、裁短、改槽或另加折痕。片展平沿用现有spine_flat_pose分支；中性层取片中面，非材料实测展开系数。
闭合包覆尺寸基于参考手机117.8×84.1×11.3，非官方机械图。护轴片端部各退1.9，胶片中面Z1.7、滑片中面Z16.8，间距15.1，两90°弧中性半径1.6，直段11.9；无需伸长材料。打开时自由片及尾片收纳总长46.926548对槽49，尾余2.073452；槽销前向极限18.05，对回缩16.926548余程1.123452。
镜头圈不变：内55×23、外59×27，中心(10,42.5)，浅座0.4，胶层0.15；镜头凸高4和余高0.5仍为假定。

## Poses and validation
护轴片展示姿态：spine_flat_pose=true，spine位置[110,0,1.9]，旋转[0,0,0]；片下表面Z0、上表面Z0.6。其余四件不动。当前仅证明平片形状、尺寸和分件摆放，不以脱离装配状态验证开合接口。
闭合复现build83：spine_flat_pose=false，片位置[−43.9,0,3.3]；前盖[0,0,14.85]和压盖[−18.3,0,15.05]均无旋转。
展开收纳复现build80：spine_flat_pose=true，片位置[−43.9,0,3.3]；前盖[−87.8,0,3.65]、压盖[−69.5,0,3.45]均旋转[0,180,0]。不要只改片而忘记恢复对应位置。
此前两态均五实体、10对无体积相交；闭合片到槽底0.35、两片内面Z差14.5、胶端距贴机面Z差0.4。当前保持该物理设计，只变片的展开状态和摆放。真实中间轨迹、自动回缩、摩擦屈曲、疲劳、跌落、切边后保持力尚未实测，不能以STEP代替验证。

## Connections
free：背盖剩余弹性扣边、片/背胶接、片/前盖双销槽、压盖/前盖三边胶接、镜头圈/背盖胶接。当前为拆出的片，胶接和导向连接不处于连接位置；没有删除这些装配接口。

## 正面装饰与安装座
正面五个嵌件为蓝白一体嵌件、黄色向内三角、红黄绿三个小球；另有八个内侧嵌件，当前共18个装配对象。蓝白嵌件以同一对象内两个共面相接的颜色区域保存，需共同成形为一个部件；联合后单一连续实体。STEP共19实体，没有增加第二个独立白底安装件。
正视坐标X右Y上。蓝底座Ø18×1，蓝半球R7，XY=(-29,44)；三个球R1.8、平底座厚0.25，XY=(-10,49.2)、(-3,49.2)、(4,49.2)。节距7，蓝半球和小球的正视轮廓顶边均Y=51。此处齐平按参考图的平面顶边解释，非凸起高度相同。
三角7×9×0.9，中心(34,0)，尖端向左。下部胶囊槽34×2.4，中心(0,-44)，不增加长条嵌件。
外面Z18.85，所有浅槽深0.2、槽底Z18.65，嵌件底面Z18.70，预留0.05胶层；侧向每边0.15。嵌入0.15。收纳腔上方局部剩余厚1.2，其他区域沿用原厚度；未挖穿收纳腔。所有新尺寸均为可调默认，位置用各对象的绝对放置保存。
浅槽与嵌件尺寸为配套参数；改装饰尺寸或位置时须同步对应座参数与对象放置。上盖红、三角黄、半球蓝、底座白、小球红黄绿，颜色已进入STEP；工具的形状检查预览为灰色。
free连接：五个正面嵌件均胶接浅座；没有卡扣、灯光、电路或新增螺钉。

## 前盖背面与独立盖板的装饰
内侧按用户参考图新增八件：顶部黑色长块、整体蓝色十格块、右下两根圆角短条、下方左侧白色双格块与右侧黄色圆饼、底部左右两块黑色长方块。
内侧正视坐标u向右v向上，对应前盖闭合局部X=-u,Y=v；外露方向-Z。顶部黑块62×18、(u,v)=(0,31)，蓝块62×20、(0,8)；短条10×1.6、(15,-6)/(26,-6)，白块24×9、(-20,-18)，圆饼Ø7、(25,-23)，底部黑块各24×10、(-20,-40)/(20,-40)。均厚0.7；普通圆角0.8，短条两端半圆，圆饼边圆角0.15。
蓝块一整体实体，以宽0.5深0.25的凹线分成2行5列；白块一道相同尺寸竖向凹线，底部均保持0.45连通。模型核验蓝块可见平面10个、白块2个。
盖板外侧增加0.2薄层与前盖内面齐平，原导向/胶接面的Z位置不变。盖板总厚1.2，局部底厚0.85。上盖及盖板内面均Z14.85；座深0.15，槽底Z15，单边间隙0.15。嵌件背面Z14.95、外面Z14.25，插入0.1，凸出0.6，底部胶接间隙0.05。构建和测量确认槽深0.15、盖板剩余底厚0.85。
顶部黑块和蓝块跨两片分件缝，均保持整件，只在盖板侧施胶、前盖侧干配；白块与左下黑块胶接前盖，其余胶接盖板。连接均为free浅槽胶接，无新增卡扣或螺钉。取下盖板时，两长块随盖板向外法向移出浅槽；原三边胶接仍需解除。
闭合摆放中，八个内侧嵌件一律rotation=[0,180,0]，位置为[-u,v,14.95]。若切换旧版打开姿态，必须让新增八件和已有五个外侧嵌件一同随前盖刚体变换；不能只移动前盖/盖板。盖板内侧装饰的正视观察需隐藏back_cover、camera_guard及spine，避免闭合背壳遮挡。
新增装饰最外端Z14.25，相对既有假定外屏平面Z13.7名义0.55；没有实机实体或保护膜厚度，不把此估算当成实际屏幕接触验证。

## 握持边缘
前后盖铰链侧各两个外角保持R1.0，直边主体不变。背盖音量、底部、电源与拍照四处开口均设R1.0上下轮廓转角，触手外侧U形棱边保留R0.3小倒圆。为不挤占原矩形避让区域，转角前每个开口两端各拓宽1 mm，直立端面间距为36/52/23/25；原34/50/21/23 mm全高矩形通道与壳体交集体积逐项小于1e-6 mm³。局部凹圆角补足的是拓宽后的角部，不侵入原通道。轮廓转角和外缘小倒圆是独立可调参数。当前19实体有效，静态装配无体积相交，前后盖整体包络仍87.8×121.5。

## Making and assembly
默认背盖TPU95A、片柔性TPU0.6mm、前盖/压盖/镜头圈PETG。没有打印机配置或G-code。片宜平片制作后弯曲；此前闭合STEP不能直接作为平片下料姿态，本轮已将该片单独展平。平料名义114×54.926548×0.6，双槽随平片姿态源定义；不能把整个料长截成16.93。若FDM可试0.15mm层高四层并实测摩擦/撕裂，不保证未校准打印机的间隙。前盖外平面朝下、腔朝上；压盖平面朝下、胶座朝上。背盖外面朝下，剩余扣边悬伸用小样确认，避免支撑污染轨道。
先把双槽套在前盖销上，压盖三边施胶留0.2层，禁止进胶滑道；固化后手动试滑，再胶接背盖固定端留0.2层。镜头圈留0.15胶层，禁止溢入镜孔。先空壳慢开合检验片不屈曲、盖不脱胶，再用尺寸样块低力扣合；不要强扣实机。拆下先掀自由侧扣边；拆压盖先取手机。镜头圈可脱胶更换，不以镜头作撬点。加宽后胶边改窄，装配定位和胶量更敏感；切边后保持力下降，必须试拉脱。胶种/TPU处理未测，无疲劳跌落记录。左侧两角已设R1.0小圆角，四处按键/接口开口轮廓设R1.0、外缘设R0.3圆角；打印后仍需清除毛刺，实际握感以试样为准。

正面装饰件单独制作、平底朝下，球面朝上；蓝白嵌件按一个多色部件共同成形，白底与蓝球共面连接，不留装配间隙。球面颜色区域联合后须保持一个连续件。五个嵌件均干配检查后薄涂胶入座；0.05胶层与0.2浅槽是模型默认，实物先做工艺校准，不靠大力压入。上盖正面浅槽若朝下打印，应检查槽口首层压扁与跨桥是否封槽，不能只按未装饰的平面设置切片。局部1.2薄底不承载撬动，拆件先软化/解除胶接，不撬穿槽底。本轮未做胶接、打印或强度实测。

内侧八件平底朝下制作，蓝白凹线朝上；凹线深0.25与0.7薄片需要匹配层高并做试样。盖板新增0.2外皮与本体一体成形，非另加一片零件。先将盖板暂定位于前盖，干配八个嵌件；长黑/蓝块只在盖板范围薄涂胶，避免胶液沿分件缝流入前盖和滑道，白块/左下黑块只粘前盖。固化后再试拆盖板和滑动。内侧嵌件凸出0.6，装真机前用测量样块核对屏幕及保护膜净空；本轮没有进行实物打印、粘接或屏幕接触试验。
