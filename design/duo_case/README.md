# iPhone duo 内置宽幅收纳护轴手机壳

## Design intent
五件：弹性背盖、柔性护轴片、内侧压盖、实心前盖、独立胶粘镜头圈。依据retract_mark去除侧视两端凸出，两盖端面与护轴片同为Y±58.9，扩大尾片、内槽和压盖，让完整自由护轴段可摊平收纳。胶接端仍在前盖。保留四角内收卡接，不允许因扩大滑道而删除两角。fit_check交付；手机117.8×84.1×11.3mm为参考包络，无官方机械图。

## Interfaces
phone_fit：背板3.4mm，贴合面Z2.4，外面Z=-1，内压盖顶Z2.2。两盖全宽裁到Y±58.9，保留四处弧形角扣及0.4mm内收唇边，夹持力待实测。铰链侧两个角扣由背盖一体跨槽桥承载：桥顶Z2.4、底Z1.4、厚1mm，X[-43.9,-19]、|Y|[44.75,58.9]；立柱仅在X[-21.3,-19]、|Y|[57.7,58.9]，不进入薄片扫掠区。
flush_hinge_ends：前、背盖及护轴片同为Y±58.9，角扣不高出此端部范围。入口通道在跨槽角扣下继续贯通。
slider：主护轴117.8高、0.6厚，直段11.4、中性弯曲半径1.6；自由展开料长L=16.426548。尾片30×84，中心Y=-15，前4mm肩全高117.8。双槽21.5×3.2，中心距弯曲原点17、Y=-35/12；双销X=-17.7、Ø2.4。闭合偏置9，前向可动18.55；收纳位移16.926548，末端余量1.623452。全高腔到X=-21.5，中央腔到X5、Y[-57.5,27.5]。槽底Z0.2、薄片Z0.45–1.05，桥/压盖主顶Z1.4。胶边不得横跨运动区。
retainer：左右边X[-43.8,6.7]，最大宽50.5；实际Y[-58.9,44.5]，两铰链角留缺口X<-18.8、|Y|>44.5，改由背盖一体桥覆盖，所以不再整片高117.8。压盖与桥侧边至少0.2/0.25mm避让。
front_bond：104mm高胶接端，连接边X=-43.7，1.1mm宽让位、余厚0.8；有效胶接长6.9，胶层0.2。前盖完整实心无屏幕窗口。摊平容量姿态为位置[-86.9,0,1.25]、Y转180°；前盖距背盖槽底0.25，距新增桥底最小0.15。
camera_guard_bond：独立圈不变，孔55×23、外59×27、中心(10,42.5)，座深0.4、胶层0.15；镜头高4mm及再高0.5余量为未实测默认。

## Connections
全部free实现：四角弹性卡接、双销长槽、阶梯压盖胶接、薄片/前盖胶接、镜头圈/背盖胶接。胶不增加实体数。

## Validation boundary
闭合build51及等料长摊平build49均五个有效实体、10对无体积相交。摊平自由段X[-43.2,-26.773452]，全高肩至-22.773452，尾端3.226548，在对应预留区内；新增桥柱X起点-21.3在全高肩之外，|Y|起点57.7在尾片之外。局部薄片/压盖最小0.15、薄片/背盖最小0.25；并非全部顶间隙0.35。spine_flat_check只检查容量；不把两端姿态当作连续实机运动，不保证手机打开能自动回缩。摩擦、屈曲、疲劳、夹持与粘接均待试验。

## Making and assembly
原型默认背盖TPU95A，薄片柔性TPU0.6 mm，压盖和前盖PETG；镜头圈默认PETG。没有选择打印机或输出G-code。薄片宜平片制作后弯曲，闭合STEP不能直接当平片下料图。薄片若FDM制作可先试0.15 mm层厚、四层形成0.6 mm，再实测摩擦/撕裂；不保证未校准打印机的配合。
先将薄片两端肩部穿过背盖角扣下的通道，再从内侧把两槽套上定位销；于压盖深区端边及上下台阶施胶，不得在全长入口或滑片肩部上点胶。薄片另一端粘前盖，留0.2mm胶层。镜头圈放入外侧浅座留0.15mm胶层，防止胶流入镜头孔。固化后检查压盖低于手机贴合面；先用尺寸样块低力试扣，不可强行扣实机。拆时先掀自由侧两弹性角，拆内压盖前先取手机。镜头圈脱胶更换时禁以镜头为撬点。胶种及表面处理未实测，无疲劳、跌落测试记录。新增宽腔及跨槽桥影响刚度，优先做宽腔滑动样件。跨槽桥存在约25mm跨度及1.2mm高内部通道，FDM需选择侧向成形或可彻底去除的支撑工艺；内部残留支撑会堵槽，不能直接按闭合装配姿态打印。
