# iPhone duo 内置滑轨护轴手机壳

## Design intent
五个实体：back_cover弹性半包背盖、spine柔性护轴片、retainer内埋压盖、front_cover完整实心前盖、camera_guard独立胶粘镜头保护圈。按本轮mark.png和用户文字将滑槽、销与压盖置于背盖内侧。手机参考包络和镜头孔/按键XY位置沿用试配版本，非官方机械图；交付目标fit_check。

## Interfaces
phone_fit：手机贴合面Z2.4不动，背板厚由2.4改3.4mm，向外加厚至Z=-1。半包壁1.6mm、侧隙0.25mm、四角内扣0.4mm及按键避空保留，后半手机5.2mm厚。
slider：内侧深槽底Z0.2，尾片Z0.45–1.05，双销Ø2.4顶Z1.3，压盖滑动内面Z1.4。压盖顶Z2.2，低于手机安装面0.2mm；三边胶座Z1.0，胶接面Z1.2，留胶0.2mm。两槽14.5×3.2mm；相对闭合姿态允许[-0.8,+11.3]mm，正向11.3mm触及槽端，没有额外末端余量。主护轴厚0.6mm、高117.8mm；尾端位置上移0.1mm，前盖连接端不动，直立段11.4mm。
front_bond：实心完整前盖原有胶接凹槽不动，胶层0.2mm。
camera_guard_bond：内孔55×23mm，外廓59×27mm胶囊环；外侧对应浅座59.4×27.4mm深0.4mm，环底Z=-0.75、座底Z=-0.6，胶层0.15mm、单边0.2mm间隙。镜头高出手机背面4mm为假定（不是实测）；圈顶Z=-2.1，比该假定镜头顶Z=-1.6向外多0.5mm，比外背面凸起1.1mm。必须实测后调整，不能声称镜头保护余高已验证。

## Connections
free实现：手机与背盖弹性角扣；spine/back_cover双销长槽；retainer/back_cover内侧三边胶接；spine/front_cover凹槽胶接；camera_guard/back_cover外侧环形座胶接。没有五金或额外实体，胶为工艺辅料。手机不以虚构实体导入。

## Validation boundary
检查五个各自连通的实体、背盖外平面不露滑盖、拆前盖显示内埋压盖、拆压盖显示双销双槽、独立镜头圈及座、静态干涉、压盖低于手机贴合面和胶层间隙。弯曲片只是安装姿态；实际折叠扫掠、自动回缩、疲劳、跌落和镜头凸高均未实测。

## Making and assembly
原型默认背盖TPU95A，薄片柔性TPU0.6 mm，压盖和前盖PETG；新增镜头圈也默认PETG。没有选择打印机或输出G-code。薄片宜平片制作后弯曲，STEP显示安装后的曲面形状，不能把此姿态直接当作平片下料图。薄片若FDM制作可先试0.15 mm层厚、四层形成0.6 mm，再实测摩擦/撕裂；不保证未校准打印机的配合。
先从背盖内侧把薄片两槽套上定位销，再在压盖三条固定胶边施胶，禁止胶进入滑道；安装另一端到前盖槽，留0.2 mm胶层并定位固化。镜头圈放入背盖外侧浅座，留0.15mm胶层，防止胶流入镜头孔。所有胶固化后检查压盖不高于手机贴合面，最后装手机，先用尺寸样块低力试扣，不可强行扣实机。取下时先掀自由侧两个弹性角，拆内侧压盖前必须取出手机。镜头圈可脱胶更换，禁止以镜头作撬动支点。胶种与TPU表面处理未实测；没有疲劳或跌落测试记录。
