# iPhone duo 加宽护轴片／前盖收纳壳

## Design intent
五件：back_cover弹性背盖、spine柔性片、retainer内压盖、front_cover实心前盖、camera_guard镜头圈。滑动/收纳/双销及压盖在前盖内侧，固定片胶接背盖，左直右圆轮廓保留。此前切边按铰链侧上下残留竖边解释，保留顶底回边与右侧扣边。本轮用户20260924T095306161Z-1-mark.png要求只将护轴片打平作为独立分件，总展开长度与轮廓不变。
当前build85为展示/分件状态：护轴片展平并独立摆于壳体右侧，没有复制第六件；其他四件仍保持build83的闭合位置和形状。不是当前仍胶接或联动的装配姿态。

## Interfaces
保留所有装配尺寸。各盖87.8×121.5，背板3.4、贴机Z2.4、壁1.6、内扣0.4；铰链侧X[−43.9,−41.7]且Z≥2.4的原竖边移除。背胶座8.3×115深1.2，胶层0.2。前盖厚4，49×115.4深2.6收纳腔、51.4×119深1.4压盖座；压盖51×118.6×1，侧胶边1.4、端胶边2.3。双销Ø2.4，X−18.9,Y±25。
护轴片114宽、0.6厚，胶端8、滑尾30；自由中性料长11.9+π×1.6=16.926548，总平料长54.926548mm。双槽22.5×3.2，沿片Y±25间距50，平片槽心局部X−33.926548。没有缩放、裁短、改槽或另加折痕。片展平沿用现有spine_flat_pose分支；中性层取片中面，非材料实测展开系数。
闭合包覆尺寸基于参考手机117.8×84.1×11.3，非官方机械图。护轴片端部各退1.9，胶片中面Z1.7、滑片中面Z16.8，间距15.1，两90°弧中性半径1.6，直段11.9；无需伸长材料。打开时自由片及尾片收纳总长46.926548对槽49，尾余2.073452；槽销前向极限18.05，对回缩16.926548余程1.123452。
镜头圈不变：内55×23、外59×27，中心(10,42.5)，浅座0.4，胶层0.15；镜头凸高4和余高0.5仍为假定。

## Poses and validation
当前分件build85：spine_flat_pose=true，spine位置[110,0,1.9]，旋转[0,0,0]；片下表面Z0、上表面Z0.6。其余四件不动。当前仅证明平片形状、尺寸和分件摆放，不以脱离装配状态验证开合接口。
闭合复现build83：spine_flat_pose=false，片位置[−43.9,0,3.3]；前盖[0,0,14.85]和压盖[−18.3,0,15.05]均无旋转。
展开收纳复现build80：spine_flat_pose=true，片位置[−43.9,0,3.3]；前盖[−87.8,0,3.65]、压盖[−69.5,0,3.45]均旋转[0,180,0]。不要只改片而忘记恢复对应位置。
此前两态均五实体、10对无体积相交；闭合片到槽底0.35、两片内面Z差14.5、胶端距贴机面Z差0.4。当前保持该物理设计，只变片的展开状态和摆放。真实中间轨迹、自动回缩、摩擦屈曲、疲劳、跌落、切边后保持力尚未实测，不能以STEP代替验证。

## Connections
free：背盖剩余弹性扣边、片/背胶接、片/前盖双销槽、压盖/前盖三边胶接、镜头圈/背盖胶接。当前为拆出的片，胶接和导向连接不处于连接位置；没有删除这些装配接口。

## Making and assembly
默认背盖TPU95A、片柔性TPU0.6mm、前盖/压盖/镜头圈PETG。没有打印机配置或G-code。片宜平片制作后弯曲；此前闭合STEP不能直接作为平片下料姿态，本轮已将该片单独展平。平料名义114×54.926548×0.6，双槽随平片姿态源定义；不能把整个料长截成16.93。若FDM可试0.15mm层高四层并实测摩擦/撕裂，不保证未校准打印机的间隙。前盖外平面朝下、腔朝上；压盖平面朝下、胶座朝上。背盖外面朝下，剩余扣边悬伸用小样确认，避免支撑污染轨道。
先把双槽套在前盖销上，压盖三边施胶留0.2层，禁止进胶滑道；固化后手动试滑，再胶接背盖固定端留0.2层。镜头圈留0.15胶层，禁止溢入镜孔。先空壳慢开合检验片不屈曲、盖不脱胶，再用尺寸样块低力扣合；不要强扣实机。拆下先掀自由侧扣边；拆压盖先取手机。镜头圈可脱胶更换，不以镜头作撬点。加宽后胶边改窄，装配定位和胶量更敏感；切边后保持力下降，必须试拉脱。胶种/TPU处理未测，无疲劳跌落记录。左角名义方角需去毛刺，可按实测微倒钝，不恢复大圆角。
