# iPhone duo 前盖收纳式五件护轴壳

## Design intent
按用户本轮标记front_storage_mark：滑槽、双销、收纳固定结构和压盖迁到前盖内侧；另一端直接胶粘背盖。打开两直边并拢时，自由护轴段和滑尾完整收纳在前盖。胶接端留在背盖；不能将其也滑进前盖。仍为五件：back_cover、spine、retainer、front_cover、camera_guard。左直右圆轮廓、四角扣边及镜头圈保留。交付fit_check，不是实机机械图认证。

## Interfaces
phone_fit：参考闭合117.8×84.1×11.3，背半机厚5.2；各盖外廓87.8×121.5。背盖TPU板厚3.4，贴机Z2.4、外面Z−1、侧壁1.6、侧隙0.25、角扣0.4；左角方、右内半径10。前盖PETG厚4，右角半径11.6。
back_bond：背盖移除原滑道/销，内侧左边8.3×85深1.2胶槽；底Z1.2，固定片8×84，片Z1.4–2.0，留0.2胶层。未移动镜头与按键。
slider：前盖内侧49×85.4深2.6收纳腔、残底1.4、阶梯胶座51.4×90.6深1.4。双销Ø2.4局部X−18.9、Y±25，销端局部Z1.3。压盖51×90×1，内面让位0.2，端胶边2.3、侧胶边2.1；三边胶层0.2，开口朝铰链。压盖距前盖内表面0.2，薄片距槽底0.35、侧边0.7。销端到压盖内面0.3小于片厚0.6，名义防脱。
spine：片厚0.6，覆盖宽84居中（用户授权改宽），尾长30，胶端长8，弯曲中性半径1.6，直立段11.9。两槽22.5×3.2，局部弯根起槽心17，Y±25；自由料长11.9+π1.6=16.926548，总平料长54.926548。
open_edge_meeting：打开两盖直边X−43.9名义接触，无体积重叠。自由片和滑尾X[−90.826548,−43.9]全在前盖槽X[−92.9,−43.9]，Y±42对槽±42.7，Z1.4–2.0对槽底1.05及盖内面2.65。背盖胶端X[−43.9,−35.9]不移动。尾端余量2.073452，槽销前向极限18.05，相对闭合退入16.926548，余程1.123452。
camera_guard_bond：原独立胶囊圈内55×23、外59×27，中心(10,42.5)，外座深0.4，胶层0.15。凸高4及保护余高0.5是假定；真实镜头待实测。

## Poses and validation
当前build73为打开端点：spine_flat_pose=true，spine位置[−43.9,0,3.3]，前盖[−87.8,0,3.65]旋转[0,180,0]，压盖[−69.5,0,3.45]旋转[0,180,0]；背盖/镜头不动。
闭合验证build70：spine_flat_pose=false，spine位置同上；前盖[0,0,14.85]无旋转，压盖[−18.3,0,15.05]无旋转。一次链式设置三项可切换，尺寸不得另改。两姿态同中性料长，不是真实铰链连续仿真。
闭合和打开各五有效单实体，10对均无体积相交。打开两盖0mm接触，片/槽底实测0.35mm满足≥0.3。隐藏压盖查看完整入槽及双销槽；隐藏对象视图不证明压盖本身。照片及真实铰链扫掠、自动回缩、各中间角度、摩擦、疲劳、跌落尚未验证。展开手机宽164.6不等于本壳前盖翻开位置；本版不能宣称已实现真实手机运动驱动或实机保证。

## Connections
全部free实现：背盖四角弹性卡扣；背盖/薄片凹槽胶接；前盖/薄片双销双槽；压盖/前盖三边胶接；镜头圈/背盖浅座胶接。无螺纹、无新增五件之外的零件，胶不建实体。

## Making and assembly
原型默认背盖TPU95A、片柔性TPU0.6mm、前盖/压盖/镜头圈PETG。未选择打印机或输出G-code。薄片先平片制作后弯曲；当前打开姿态就是理想平片，中性长度不变。若FDM可先试0.15mm层厚四层后实测摩擦/撕裂；不保证未校准打印机的配合。前盖用完整外平面朝下、腔朝上，避免支撑污染滑道；压盖平面朝下，三边胶座朝上。背盖外平面朝下，角扣悬伸需用小样确认，不向卡扣根部强行剥支撑。
先把薄片双槽套上前盖定位销；在压盖三胶边施胶并保持0.2胶层，禁止胶入轨道，固化后先手动试滑。再把另一端胶入背盖浅座并留0.2胶层，定位固化。镜头圈外座留0.15胶层防溢入镜孔。先空壳慢速开合，检查薄片无屈曲、压盖无脱胶，再用尺寸样块低力试扣；不可强扣实机。取下时先掀背盖自由侧角扣；拆胶接压盖前取出手机。镜头圈可脱胶更换，禁止以镜头作撬点。胶种与TPU表面处理未测试，无疲劳或跌落实物记录。左角名义方角须无毛刺，可按实测微倒钝，不恢复大圆角。
