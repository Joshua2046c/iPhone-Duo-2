# iPhone duo 四件式滑动护轴手机壳

## Design intent
按 product/requirements.json 与三张图片建立四个实体：弹性四角内扣半包背盖 back_cover、柔性护轴片 spine、滑动压盖 retainer、完整遮住外屏的前盖 front_cover。参考手机闭合117.8×84.1×11.3 mm，展开厚5.2 mm。摄像头为横向胶囊孔55×23 mm；按钮位置与圆角为可调整的图片估值，不是官方机械尺寸。交付目标是 fit_check，不宣称实机适配或可直接量产。

## Interfaces
phone_fit：背盖底2.4 mm、壁1.6 mm、单边0.25 mm间隙，四角内收0.4 mm，壁只包住5.2 mm背半机。顶部音量孔、自由侧电源孔与拍照孔、底部开口。
slider：外侧浅凹座容纳压盖，深槽1.2 mm；两凸点Ø2.4 mm，片上两长槽14.5×3.2 mm。名义行程11.3 mm，滑动片尾宽73 mm，避开相机。主护轴高117.8 mm，厚0.6 mm；闭合显示为两圆角连接11.5 mm长的直立护轴段。实际展开料长含弯曲与两端埋入段，并非仅手机厚度。
front_bond：前盖完整实心，背面胶接凹槽，护轴片上端8×104 mm胶接片，0.2 mm胶层。前盖与背盖采用闭合状态装配，手机不以假模型加入。

## Connections
全部为明确的free实现，无标准五金：手机/背盖为弹性角扣；护轴片/背盖为双销长槽；压盖/背盖为三边胶接；护轴片/前盖为凹槽胶接。没有未处理的连接。压盖防脱但不夹紧薄片，无螺钉，无第五个定制零件。

## Validation boundary
看闭合装配、背盖内外面及独立薄片，检查4个各自连通的实体、孔槽尺寸、静态无意干涉和槽销几何允许行程。CAD中柔性薄片的弯曲是姿态展示，不是弹性运动仿真。实际铰链扫掠、11.3 mm回缩是否满足全展开、槽端寿命、TPU回弹和胶强度均待实物验证。

## Making and assembly
原型默认背盖TPU95A，薄片柔性TPU0.6 mm，压盖和前盖PETG。没有选择打印机或输出G-code。薄片宜平片制作后弯曲，STEP显示安装后的曲面形状，不能把此姿态直接当作平片下料图。薄片若FDM制作可先试0.15 mm层厚、四层形成0.6 mm，再实测摩擦/撕裂；不保证未校准打印机的配合。
先把薄片两长槽套上定位凸点，再在压盖三条固定胶边施胶，禁止胶进入滑道；安装另一端到前盖槽，留0.2 mm胶层并定位固化。最后装手机，先用尺寸样块低力试扣，不可强行扣实机。取下时先掀自由侧两个弹性角，拆压盖前必须取出手机。胶种与TPU表面处理未实测；没有疲劳或跌落测试记录。
