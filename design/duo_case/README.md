# iPhone duo 加宽护轴片／前盖收纳壳

## Design intent
五件：back_cover弹性背盖、spine柔性片、retainer内压盖、front_cover实心前盖、camera_guard镜头圈。滑动/收纳/双销及压盖在前盖内侧，固定片胶接背盖；左直右圆轮廓保留。当前请求wide_shield_request：切掉后壳两段边并将护轴片加宽至接近整机，助手计算闭合包覆长度。新mark截图未收到，只有标记百分比；已公开按铰链侧上下残留竖边解释，而非顶底整个横边，详见引用文件。不是逐像素定位，也不是实机认证。

## Poses and validation
当前闭合build83：spine_flat_pose=false，spine位置[−43.9,0,3.3]无旋转；前盖[0,0,14.85]无旋转；压盖[−18.3,0,15.05]无旋转。
加宽打开验证build80：spine_flat_pose=true，spine位置不变；前盖[−87.8,0,3.65]旋转[0,180,0]；压盖[−69.5,0,3.45]旋转[0,180,0]。三项联动切换，片尺寸不变。
两态均5有效单实体、10对无体积相交；打开前背盖0接触。闭合精确测量：片到槽底0.35≥0.3，片上下内面Z差14.5，胶端距手机安装基准Z差0.4。前/左/iso_back图确认闭合U形包覆，打开隐藏压盖图确认整片收纳；隐藏图不证明所隐藏件。真实中间轨迹、自动回缩、摩擦屈曲、疲劳/跌落和保持力未验证。手机164.6展开宽不等于该实心前翻盖的开盖运动。

## Connections
free：背盖剩余弹性扣边、背盖与护轴片浅座胶接、护轴片与前盖双销槽、压盖与前盖三边胶接、镜头圈与背盖胶接。无螺纹，胶不另建实体。

## Making and assembly
默认背盖TPU95A、片柔性TPU0.6mm、前盖/压盖/镜头圈PETG。没有打印机配置或G-code。片宜平片制作后弯曲；当前闭合STEP不能直接作为平片下料姿态。平料名义114×54.926548×0.6，双槽随平片姿态源定义；不能把整个料长截成16.93。若FDM可试0.15mm层高四层并实测摩擦/撕裂，不保证未校准打印机的间隙。前盖外平面朝下、腔朝上；压盖平面朝下、胶座朝上。背盖外面朝下，剩余扣边悬伸用小样确认，避免支撑污染轨道。
先把双槽套在前盖销上，压盖三边施胶留0.2层，禁止进胶滑道；固化后手动试滑，再胶接背盖固定端留0.2层。镜头圈留0.15胶层，禁止溢入镜孔。先空壳慢开合检验片不屈曲、盖不脱胶，再用尺寸样块低力扣合；不要强扣实机。拆下先掀自由侧扣边；拆压盖先取手机。镜头圈可脱胶更换，不以镜头作撬点。加宽后胶边改窄，装配定位和胶量更敏感；切边后保持力下降，必须试拉脱。胶种/TPU处理未测，无疲劳跌落记录。左角名义方角需去毛刺，可按实测微倒钝，不恢复大圆角。
